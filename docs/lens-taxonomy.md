# SystemLens Lens Taxonomy v0.1

## 1. Systems Thinking
Purpose:
Understand structure, interactions, feedback, boundaries and leverage points.

Core operations:
- Define system boundary
- Identify actors
- Identify variables
- Map relationships
- Detect reinforcing loops
- Detect balancing loops
- Identify delays
- Identify bottlenecks
- Identify leverage points
- Analyze shocks
- Analyze system fractures

## 2. Critical Thinking
Purpose:
Evaluate whether claims and conclusions are well supported.

Core operations:
- Identify main claim
- Identify supporting evidence
- Identify assumptions
- Detect missing evidence
- Generate counterarguments
- Test alternative explanations
- Identify logical weaknesses
- Ask what would falsify the claim

## 3. Causal Reasoning
Purpose:
Distinguish correlation from causation and test causal explanations.

Core operations:
- Identify proposed cause
- Identify proposed effect
- Detect confounders
- Test reverse causation
- Generate competing causal explanations
- Ask counterfactual questions
- Build causal chain
- Assess causal confidence

## 4. Decision Making
Purpose:
Compare alternatives under uncertainty and trade-offs.

Core operations:
- Define decision
- Generate alternatives
- Identify constraints
- Identify opportunity cost
- Evaluate reversibility
- Estimate upside/downside
- Identify uncertainty
- Run pre-mortem
- Compare scenarios
- Recommend next information to collect

## 5. Probabilistic Thinking
Purpose:
Reason explicitly about uncertainty.

Core operations:
- Identify base rate
- Estimate probability
- Separate confidence from certainty
- Update belief with new evidence
- Identify overconfidence
- Compare prior and posterior belief

## 6. Forecasting
Purpose:
Reason about possible future states.

Core operations:
- Define forecast target
- Decompose drivers
- Build scenarios
- Identify leading indicators
- Identify assumptions
- Assign probabilities
- Define update triggers

## 7. Scientific Reasoning
Purpose:
Test explanations against evidence.

Core operations:
- Form hypothesis
- Define falsification condition
- Design experiment
- Identify measurable variables
- Separate observation from interpretation
- Assess evidence quality

## 8. Problem Solving
Purpose:
Turn an ambiguous problem into actionable structure.

Core operations:
- Define problem
- Decompose problem
- Identify constraints
- Identify root causes
- Identify bottleneck
- Use inversion
- Generate solution options
- Select minimum viable intervention

## 9. Argumentation
Purpose:
Analyze structured disagreement.

Core operations:
- Identify premises
- Identify conclusion
- Test premise relevance
- Test premise sufficiency
- Identify burden of proof
- Generate critical questions
- Compare competing arguments

## 10. Metacognition & Bias
Purpose:
Challenge the quality of the reasoning process itself.

Core operations:
- Detect confirmation bias
- Detect motivated reasoning
- Detect sunk-cost thinking
- Detect availability bias
- Detect framing effects
- Identify blind spots
- Ask what would change my mind
- Calibrate confidence
